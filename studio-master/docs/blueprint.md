# **App Name**: CineMatch AI

## Core Features:

- AI Movie Recommendations: Generate personalized movie suggestions using ML models (e.g., TF-IDF with cosine similarity or GPT API). Include optional mood-based filtering and prompt-driven AI suggestions. Includes a tool for prompt driven AI suggestions.
- User Profiles: Enable users to create and manage profiles, save favorite movies, track viewing history, and receive tailored recommendations.
- Advanced Search: Implement real-time, fuzzy search by title, genre, actor, director, or keyword. Optionally add voice search.
- Movie Detail Pages: Include trailers, cast, synopsis, runtime, genres, ratings, and similar movie suggestions.
- Ratings & Reviews: Allow users to rate movies, leave reviews, and see community opinions. Use sentiment analysis tags optionally.
- Curated Lists: Display trending, top-rated, genre-specific, and AI-curated movie lists dynamically.

## Style Guidelines:

- Primary Color: Deep Purple `#673AB7`
- Background Color: Dark Grey `#303030`
- Accent Color: Electric Green `#7CFC00`
- Font Pairing: 'Poppins' for headings, 'PT Sans' for body text
- 3D hover effects using `React Tilt` or similar
- Animations via `Framer Motion` or `GSAP`
- Grid-based layout and minimalist icons (e.g., Heroicons)
